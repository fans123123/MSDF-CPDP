# MSDF-CPDP

Original project archive and experimental data shared for the MSDF-CPDP paper.

## Downloads

| File | Contents | Size |
| --- | --- | --- |
| [MSDF-CPDP.zip](https://github.com/fans123123/MSDF-CPDP/releases/download/v1.0.0/MSDF-CPDP.zip) | Original project archive, including Python source code, tools, and model weights | 408,789,989 bytes (389.85 MiB) |
| [data.zip](https://github.com/fans123123/MSDF-CPDP/releases/download/v1.0.0/data.zip) | Experimental results: 8 Excel workbooks and `OURS.csv` | 78,701 bytes (76.86 KiB) |

Both files are provided unchanged from the original archives. Download the two named assets from [Release v1.0.0](https://github.com/fans123123/MSDF-CPDP/releases/tag/v1.0.0).

The experimental tables include metrics such as MCC, BACC, AUC, and F1. The project archive includes local paths in `run_tgnn.py`; adapt these paths to your environment before running experiments.

GitHub's automatically generated **Source code (zip)** and **Source code (tar.gz)** downloads contain the repository files. Use the **MSDF-CPDP.zip** and **data.zip** assets above for the original shared materials.
